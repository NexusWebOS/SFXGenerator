# Bullets of Fury — Arcade PCM V2 preview bank

A separate arcade-quality audition set. V1 and all existing game files remain untouched.

- 42 individual stereo WAV sounds
- 6 seamless looping beds with WAV `smpl` loop metadata
- 48 kHz, 16-bit stereo PCM
- Layered transients, filtered noise, body/sub, stereo diffusion, cabinet reflections and saturation
- Deterministic synthesis with no third-party samples
- Open `index.html` to audition everything
- `bullets_of_fury_arcade_v2_preview_reel.wav` is a quick sequential sampler

Regenerate from the repository root with:

```powershell
node .\generate_bullets_of_fury_arcade_v2.js
```
