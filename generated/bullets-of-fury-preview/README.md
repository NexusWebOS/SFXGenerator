# Bullets of Fury — ColeSFX preview bank

Preview-only procedural sound set. No existing game files were replaced.

- 42 individual stereo WAV sounds
- 6 seamless looping beds with WAV `smpl` loop metadata
- 48 kHz, 16-bit PCM
- Deterministic synthesis with no third-party samples
- Open `index.html` to audition everything
- `bullets_of_fury_preview_reel.wav` is a quick sequential sampler

Regenerate from the repository root with:

```powershell
node .\generate_bullets_of_fury_sfx.js
```
